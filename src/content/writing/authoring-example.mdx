## Luau code

The `luau` fence uses a dedicated Luau grammar, including types and string interpolation.

```luau title="example.luau"
--!strict
export type Point = { x: number, y: number }

local point: Point = { x = 3, y = 4 }
local label = `Point: {point.x}, {point.y}`

for index = 1, 5 do
    if index == 2 then
        continue
    end

    print(label, index)
end
```
